## 🎯 About The Project

**Application Structure**
<p align="center">
  <img src="./assets/appStr.jpg" alt="Project Structure" width="600">
</p>

This project is an application that will help project finance professionals manage their expenditures in recording and tracking with all administrative control. This might be ideal for projects which are run in partnership funding and implementation where portion of the expenditure is allocated to different fund sources.
